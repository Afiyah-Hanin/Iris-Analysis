# Iris Analysis

This project performs Exploratory Data Analysis (EDA) on the Iris dataset using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Objective
To explore the Iris dataset and understand the characteristics of different Iris flower species.

## Project Work
- Loading the dataset
- Data inspection
- Checking missing values
- Descriptive statistics
- Data visualization
- Exploring relationships between features
- Analysis of Iris species

## Dataset
The dataset contains measurements of Sepal Length, Sepal Width, Petal Length, and Petal Width for different Iris species.

## Files
- `Amber_iris.ipynb` — Main Iris analysis notebook

## Conclusion
The project uses Python data analysis and visualization techniques to explore the Iris dataset.
